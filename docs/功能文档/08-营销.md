# 营销

产品：指掌天下（经典模式）。只记录实际打开页面上看到的按钮、筛选和列，不含活动内容和金额。只读查看，未点新增、发放、保存或导出。

顶部「营销」分成三组。

- 商品促销：限时特价、单品买赠、阶梯价、组合促销、优惠套餐
- 下单增长：整单优惠、优惠券
- 拓客留客：积分、分销、预收款储值

商品促销和整单优惠的列表很像：按活动时间筛选，看购买客户数和订、出、退、实销，可以排序。每页 30 条。本次这些列表都是空的，空状态是「暂无搜索结果」。日期快捷是昨天、今天、上周、本周、上月、本月、本年、更多。
