# 单据

产品：指掌天下（经典模式）。本文件只记录实际打开页面上看到的结构，不含客户、金额和单据内容。

单据模块的入口是顶部「单据」，打开后进入单据中心。侧边「单据目录」里的具体单据类型点击后只是选中目录项，地址仍停在单据中心，没有各自独立的列表页。各单据的独立列表在「销售」「采购」「库存」模块里。

## 单据中心

- 路径：`/pmweb/dhpc/reports/bill/center`
- 页签：首页、单据
- 作用：按时间和条件查看、筛选各类业务单据。

### 工具栏

- 导出
- 时间快捷：昨天、今天、上周、本周、上月、本月、本年
- 更多
- 查询

### 筛选

- 开始时间、结束时间
- 只显示草稿单
- 单据编号
- 往来单位
- 单据状态
- 支付状态

### 列表列

单据类型、单据状态、往来单位、经手人、数量、入库仓库、出库仓库、单据金额、收付款账户、收付款金额、支付状态、单据备注、过账时间、打印次数、单号、录单时间。

### 侧边单据目录

点击下列项会选中目录，页面不跳转：

- 采购订单
- 采购类单据：采购入库单、采购退货单
- 销售订单
- 销售类单据：销售出库单、销售退货单
- 库存类单据：其他出库单、其他入库单、同价调拨单、调拨出库单(同价)、调拨入库单(同价)、调拨出库单(变价)、调拨入库单(变价)、成本调价单、组装拆装单

部分目录项旁边有「新增」快捷入口，本次未点开，避免进入可保存的录单页。

### 交互

1. 用时间快捷或开始/结束时间圈定范围，再点查询。
2. 可叠加草稿、单据编号、往来单位、单据状态、支付状态。
3. 导出在查询结果之上。
4. 目录用来缩小单据类型，结果仍在同一张表里，用「单据类型」列区分。
