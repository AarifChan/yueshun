# 库存

产品：指掌天下（经典模式）。只记录实际打开页面上看到的按钮、筛选和列，不含客户、金额和单据内容。只读查看，未点新增、导入、导出、打印、保存。

顶部「库存」分成单据、调拨、商品加工、报表。列表页上方有页签（首页以及当前页）。页签最多同时开 15 个，看完即关。多数单据列表有「显示撤销单据」。表底一般是刷新、翻页、每页条数、跳至。

## 单据

- 路径：`/pmweb/dhpc/bill/in-stock-list`
- 页签：首页、单据、其他入库单列表

筛选：搜索（请输入其他入库单号）、商品、入库仓、往来单位、显示撤销单据、查询。

列：操作、单号、录单时间、入库类型、入库收入、入库金额、往来单位、单据状态、经手人、制单人。有合计行。

行上能看到的状态和类型包括已过账、盘点报溢。新增未进入。
